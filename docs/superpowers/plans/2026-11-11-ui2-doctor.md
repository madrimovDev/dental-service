# UI-2 — Shifokor (D1–D5) Implementation Plan

> **For agentic workers:** superpowers:executing-plans. Ijro: `docs/ORCHESTRATION-GUIDE.md` (§6b vizual qabul). Steps `- [ ]`.

**Goal:** shifokorning 5 ta ekrani yangi dizaynda: Mening kunim, Bemor kartasi (4 bo'lim), Tish xaritasi, Vizit yozuvi (sahifa), Lab buyurtma.

**Architecture:** 4 lane: **A** D1 Mening kunim → D2 Bemor kartasi; **B** D3 Tish xaritasi; **C** D4 Vizit yozuvi; **D** D5 Lab buyurtma. UI-0 primitivlari, RFC-0010, generated api-client.

**Spec (har ekranning «Kod / Backend / Qabul» qatori — MAJBURIY):** `docs/superpowers/specs/2026-11-11-ui-redesign-design.md` §2.2 (UI-D1…D5), §0, §1, §4. Kanvas: `{DoctorDay,Patient,Odontogram,VisitNote,LabOrder}.dc.html` (`bun scripts/ui/canvas-shot.ts <Name>`).

## Global Constraints

- Roadmap qarorlari: bemor kartasi **4 bo'lim** (Umumiy · Davolash · Moliya · Hujjatlar va rasmlar) — usability testisiz; **presence («kim ishlayapti») qurilmaydi** (keyinga); D5'da **`labs` jadvali / `lab_id` YO'Q** (lab portali brainstormida), `due_date`/`shade` eski qatorlarda nullable, **yangi buyurtmada majburiy** (create schema + forma).
- Kreslo yoni rejimi (D3): bosish zonasi `--tap-chair` (60px) — toggle, localStorage'da (try/catch).
- Allergiya: sarlavhada doimiy `AlertBanner` (2-daraja); dori allergiyaga zid bo'lsa (D4) `CriticalActionDialog` (1-daraja), sabab tanlanadi va saqlanadi, shu bemorda qayta so'ralmaydi.
- Matnlar `t()` uz+ru — lane namespace'lari: `doctorDay.*`, `patientCard.*`, `odontogram.*`, `visitNote.*`, `labOrder.*`.
- Rol testi real permset bilan (Doctor, Doctor + Assistant, Nurse, Receptionist — kartani ko'rish chegaralari), `@owner` emas. `StateView.forbidden` 403'da.
- Migratsiyalar: **0050** — lane A (`medical_records.confirmed_at timestamptz NULL` + `confirmed_by`); **0051** — lane D (`lab_orders.due_date date NULL`, `shade text NULL`, `remake_of_id uuid NULL` FK, `remake_reason` text CHECK enum; yangi `lab_order_files` jadval + RLS (`check:rls`)).
- `/uploads` prefiks qoidasi (D5): `tenants/<t>/patients/...` → `patient_image.view` (mavjud), `tenants/<t>/lab-orders/...` → `lab_order.view`; boshqa prefiks → 403. Audit har ikkisida.
- Vizual qabul (§6b): reviewer `screenshotsViewed`; controller merge oldidan Doctor rolida o'zi tekshiradi.
