- [ ] **Step 1: Sof helper + test** (`payroll.calc.ts`):
```ts
/** Payroll qator hisobi. commissionAmount = revenue × percent/100; total = base + commission. 2 kasr yaxlitlash. */
export function computePayrollLine(
  baseSalary: number,
  attributedRevenue: number,
  commissionPercent: number,
): { commissionAmount: number; total: number } {
  const commissionAmount = Math.round(attributedRevenue * commissionPercent) / 100;
  const total = baseSalary + commissionAmount;
  return { commissionAmount, total };
}
```
> Eslatma: `revenue × percent / 100` — `Math.round(revenue*percent)/100` 2-kasr aniqlikni beradi (percent butun-foiz; masalan 1000000×10 = 10000000 /100 = 100000).

Test (vitest): 0-komissiya (`computePayrollLine(500000,0,0)` → {0, 500000}); 0-baza (`(0, 1000000, 10)` → {100000, 100000}); aralash (`(500000, 1000000, 10)` → {100000, 600000}); yaxlitlash (`(0, 333333, 10)` → commissionAmount 33333.3).
