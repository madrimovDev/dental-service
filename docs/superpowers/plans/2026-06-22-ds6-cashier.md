## Hard rules (every task)

- **Money math LOCKED.** Discount pills emit percent → call-site computes `Math.round(gross*pct/100)` absolute so'm → existing `computeNetTotal`/`buildCreatePayload`. `cashier.mappers.ts` byte-unchanged.
- **Payment toggle** maps 3 buttons to `cash`/`card`/`transfer`. No new "mixed" enum. `other` stays in type, off the toggle.
- **Print ReceiptModal** = hardcoded `'Hanken Grotesk'`/`'JetBrains Mono'` + fixed light palette; NOT theme-driven. Only `so'm` is dynamic via `t('common.currency')`.
- **Interactive POS chrome** = token-driven (`--font-sans`/`--font-mono`, not `--ui`/`--mono`); works light + dark.
- **Money strings** via `formatCurrency`/`formatNumber` (CLI-166); counts via `formatNumber`.
- **No backend / API / migration / new hook / new endpoint.** All data via existing `cashier.api.ts`/`services.api.ts`.
- **i18n only in Task F.** Other tasks reuse existing keys; if a new string is needed mid-task, stub the key and hand it to F (do not edit locales).
