Windows uchun yuklab olish
Versiya — · Hajm — · Sana —

Dastur imzolanmagan, shuning uchun Windows ogohlantirish ko'rsatadi — quyidagi 1-qadamga qarang.

O'rnatish

  1. Faylni ishga tushiring. «Windows protected your PC» oynasi chiqsa — More info → Run anyway.
  2. O'rnatishda rolni tanlang: server (klinikaning asosiy kompyuteri).
  3. Dasturni ochishdan oldin server manzilini ko'rsating. PowerShell'ni administrator sifatida ochib: 
    [Environment]::SetEnvironmentVariable("SUPERVISOR_URL","http://192.168.3.242","Machine")
  4. Dasturni oching va ta'minotchidan olgan litsenziya kalitini kiriting.

Tizim talablari

  • Windows 10 yoki 11, 64-bit
  • Kamida 2 GB bo'sh disk maydoni
  • Klinika tarmog'iga ulanish (server manziliga yeta olishi kerak)
